# MTool翻译工具

一个功能强大的 JSON 批量翻译工具，支持 12+ 种翻译引擎，专为游戏/视觉小说汉化设计。

## 功能特性

- **12+ 翻译引擎**：谷歌翻译、MyMemory、百度、有道、DeepL、微软Azure、腾讯、阿里、IBM Watson、OpenAI兼容(硅基流动/Groq/DeepSeek等)、Google Gemini、Ollama本地模型
- **自动获取模型列表**：OpenAI兼容引擎和Ollama支持一键获取可用模型，下拉选择，显示价格
- **并发翻译**：支持多线程并发，可自定义并发数
- **断点续译**：实时保存进度，中断后可继续
- **暂停/继续**：翻译过程中可暂停，不丢失当前批次
- **配置保存/加载**：整套配置(引擎、API参数、语言、并发数等)保存为 .cfg 文件
- **拖拽文件**：将 JSON 文件拖入窗口自动填入路径(需安装 tkinterdnd2)
- **指数退避重试**：区分限流/超时/授权失败，自动退避重试
- **LLM上下文参考**：自动使用前几条译文作为参考，保持术语一致性
- **费用预估**：翻译前显示总字符数和预计费用
- **详细统计报告**：条目/字符/速度/耗时等完整统计

## 安装

```bash
# 基础依赖（Python 3.8+）
pip install tkinterdnd2  # 可选，启用拖拽功能
```

## 使用

```bash
python MTool翻译工具.py
```

1. **基本设置**：选择输入/输出文件，设置源语言/目标语言、并发数
2. **API设置**：选择翻译引擎，填写 API 参数，点「测试连接」验证
3. **翻译进度**：点「开始翻译」，实时查看进度

## 推荐配置

- **省事**：谷歌翻译(免费)，啥都不用填
- **质量好**：DeepL免费版 或 硅基流动 Qwen3.5-35B-A3B
- **完全免费**：Ollama + qwen2.5:7b(需显卡) 或 硅基流动 Hunyuan-MT-7B(免费)
- **速度极快**：Groq(免费，推理速度超快) 或 谷歌翻译(免费，高并发)
