# 谷歌翻译 Cloudflare Worker 代理部署教程

## 作用

用 Cloudflare Worker 代理谷歌翻译 API，解决：
- 谷歌翻译在国内访问不稳定
- 高并发翻译时被 Google 限流（429）
- 部署多个 Worker 地址自动轮换 IP

> **2026-08 更新：`cf-worker-google-proxy.js` 已升级为「tk 签名 + 会话 Cookie」抗限流版，
> 实测单次成功率从旧版的约 20% 提升到约 90%。**

---

## 为什么旧版会一直 429（原理）

旧版只是把请求裸转发到 `translate.googleapis.com`，**没有 tk 签名、没有会话 Cookie**，
最容易被 Google 判定为机器人，而 Cloudflare 免费版又是共享数据中心 IP，于是大面积返回 429。

实测以下做法**都无法根治**：换 Worker 名字、多建同账号 Worker（出口 IP 相同）、
只换国家域名、只加 UA、降低请求频率。

新版参考 UniClawAI/google_translate、Stichoza/google-translate-php 等开源项目，做了四件事：
1. 首次请求先访问翻译主页拿**会话 Cookie**，并在边缘节点缓存 30 分钟；
2. 对每条文本用内置 TKK 算法计算 **`tk` 签名**参数；
3. 带 Cookie + tk + 浏览器请求头，在 **9 个谷歌翻译域名**里随机选一个请求；
4. 遇 429/503 自动换域名，第一轮全失败就刷新 Cookie **整轮重试一次**。

对 MTool 仍保持 `/translate_a/single` 原始返回格式，**上层完全无感，地址不用改**。

---

## 部署步骤

1. 登录 https://dash.cloudflare.com
2. 左侧菜单 → **Workers 和 Pages** → **创建** → **创建 Worker**
3. 输入 Worker 名称（如 `gt-proxy`），点击**部署**
4. 部署完成后点击**编辑代码**
5. 用同目录下 `cf-worker-google-proxy.js` 文件里的全部代码替换默认代码
6. 点击**部署**

---

## 绑定自定义域名（推荐，国内可直连）

1. 进入 Worker 详情页 → **设置** → **域名和路由** → **添加**
2. 输入子域名（如 `google.yourdomain.com`）
3. 等待 DNS 和证书生效（1-5分钟）

> workers.dev 域名在国内被墙，必须绑定自定义域名才能直连。

## 测试

浏览器访问：
```
https://你的Worker地址/translate_a/single?client=gtx&sl=en&tl=zh-CN&dt=t&q=hello
```

如果返回 `[[["你好","hello",null,null,10]],null,"en",...]` 说明部署成功。
偶尔一次 429 属正常，MTool 自带 3 次重试 + Worker 内两轮端点轮换，实际翻译基本不断。

---

## 在 MTool 翻译工具中使用

打开 MTool → **API设置** 页 → 展开**代理设置**：

- **谷歌翻译代理**：填入 `https://google.yourdomain.com`
- 多个地址用**逗号分隔**，自动轮换：
  ```
  https://google1.yourdomain.com,https://google2.yourdomain.com,https://google3.yourdomain.com
  ```
- 地址留空 = 直连（不使用代理）

---

## 多 Worker 轮换（可选）

新版单 Worker 成功率已约 90%，一般一个就够用。若跑超大量文本仍想更稳，可部署多个：

1. 重复上述部署步骤，创建 `gt-proxy1`、`gt-proxy2`...
2. **注意：同一 Cloudflare 账号的多个 Worker 出口 IP 相同**，想真正分散 IP 需要多个 CF 账号或换平台
3. 在 MTool 中用逗号分隔填写所有地址

---

## 维护：TKK 失效怎么办

代码顶部 `const TKK = [406604, 1836941114];` 是谷歌翻译的签名密钥，通常长期不变。
若以后所有请求都报 token / 签名错误（不是偶发 429），按下面更新：

1. 浏览器打开 `https://translate.google.com`，F12 查看网页源码；
2. 搜索 `TKK=eval` 或 `TKK=`，会得到类似 `TKK=eval('...')`，算出两个整数；
3. 把代码里的 `TKK` 两个数替换成新值，重新部署即可。

---

## 注意事项

1. **免费额度**：Cloudflare Worker 免费版每天 **10万次请求**，翻译工具完全够用
2. **并发设置**：谷歌免费接口建议并发 1–2（配代理池最多 3–4），别拉满
3. **兜底方案**：若仍频繁 429，临时切「必应翻译(免费)」，必应对 Cloudflare IP 限制很少
4. **想 100% 不被限**：只能换「干净 IP」——住宅代理、Vercel/Deno/EdgeOne 等其他平台、或海外 VPS
5. **生效时间**：Worker 刚部署或域名刚绑定，可能需要 1-5 分钟生效
