# 谷歌翻译 Cloudflare Worker 代理部署教程

## 作用

用 Cloudflare Worker 代理谷歌翻译 API，解决：
- 谷歌翻译在国内访问不稳定
- 高并发翻译时被 Google 限流（429）
- 部署多个 Worker 地址自动轮换 IP

---

## 部署步骤

1. 登录 https://dash.cloudflare.com
2. 左侧菜单 → **Workers 和 Pages** → **创建** → **创建 Worker**
3. 输入 Worker 名称（如 `gt-proxy`），点击**部署**
4. 部署完成后点击**编辑代码**
5. 用同目录下 `cf-worker-google-proxy.js` 文件里的全部代码替换默认代码
6. 点击**部署**

---

## 绑定自定义域名（推荐，国内可直连）

1. 进入 Worker 详情页 → **设置** → **域名和路由** → **添加**
2. 输入子域名（如 `google.yourdomain.com`）
3. 等待 DNS 和证书生效（1-5分钟）

> workers.dev 域名在国内被墙，必须绑定自定义域名才能直连。

---

## 测试

浏览器访问：
```
https://你的Worker地址/translate_a/single?client=gtx&sl=en&tl=zh-CN&dt=t&q=hello
```

如果返回 `[["你好","hello",null,null,1]]` 说明部署成功。

---

## 在 MTool 翻译工具中使用

打开 MTool → **API设置** 页 → 展开**代理设置**：

- **谷歌翻译代理**：填入 `https://google.yourdomain.com`
- 多个地址用**逗号分隔**，自动轮换：
  ```
  https://google1.yourdomain.com,https://google2.yourdomain.com,https://google3.yourdomain.com
  ```
- 地址留空 = 直连（不使用代理）

---

## 多 Worker 轮换（推荐）

谷歌翻译对 Cloudflare 数据中心 IP 限流较严，建议部署 3-6 个 Worker：

1. 重复上述部署步骤，创建 `gt-proxy1`、`gt-proxy2`、`gt-proxy3`...
2. 每个 Worker 绑定不同的子域名
3. 在 MTool 中用逗号分隔填写所有地址

---

## 注意事项

1. **免费额度**：Cloudflare Worker 免费版每天 **10万次请求**，翻译工具完全够用
2. **谷歌限流**：Google 会识别数据中心 IP，可能返回 429。建议：
   - 并发数设为 3-8
   - 部署多个 Worker 轮换
   - 或改用必应翻译（必应对 Cloudflare IP 限制较少）
3. **生效时间**：Worker 刚部署或域名刚绑定，可能需要 1-5 分钟生效
