# 必应翻译 Cloudflare Worker 代理部署教程

## 作用

用 Cloudflare Worker 代理必应翻译，解决：
- 必应翻译在国内访问不稳定
- 高并发翻译时被限流
- 必应对 Cloudflare IP 限制较少，推荐作为主力翻译引擎 / 谷歌被限流时的兜底

> 通用反向代理代码改自开源项目 [cf-workers-proxy](https://github.com/jonssonyan/cf-workers-proxy)（GPL-3.0协议）。
> **2026-08 修复两个问题：① POST 请求体转发 500；② 上游域名必须用 `cn.bing.com`。**

---

## 两个关键坑（务必注意）

### 坑 1：上游域名必须是 `cn.bing.com`，不能用 `www.bing.com`
- 代理到 `www.bing.com`：翻译接口 POST 返回 200 但**响应体为空**，拿不到译文；
- 代理到 `cn.bing.com`：正常返回译文。
- 所以环境变量 `PROXY_HOSTNAME` 的值**必须填 `cn.bing.com`**。

### 坑 2：POST 请求体会导致 50（旧版 bug，本目录代码已修复）
旧版通用反代直接透传请求体流（`body: request.body`）又保留了 content-length，
Cloudflare 转发 POST 时会抛异常返回 500。新版改为：POST/PUT/PATCH 先把请求体读成
ArrayBuffer 再转发，并删除 host / content-length / accept-encoding 等逐跳头。
**直接用本目录最新的 `_worker.js` 即可，不要用网上的旧版。**

---

## 部署步骤

必应翻译使用通用反向代理 `_worker.js`，通过环境变量配置目标域名。

1. 登录 https://dash.cloudflare.com
2. **Workers 和 Pages** → **创建** → **创建 Worker**
3. 输入名称（如 `bing-proxy`），点击**部署**
4. 点击**编辑代码**，用同目录下 `_worker.js` 文件里的全部代码替换默认代码
5. 点击**部署**
6. 回到 Worker 详情页 → **设置** → **变量** → **添加变量**
   - 变量名：`PROXY_HOSTNAME`
   - 值：**`cn.bing.com`**（不要填 www.bing.com）
   - 再添加：变量名 `PROXY_PROTOCOL`，值 `https`
   - 点击**保存并部署**

> 用 Wrangler 命令行部署时，直接用本目录 `wrangler.toml`（已配好 `cn.bing.com`）。

---

## 绑定自定义域名（推荐，国内可直连）

1. 进入 Worker 详情页 → **设置** → **域名和路由** → **添加**
2. 输入子域名（如 `bing.yourdomain.com`）
3. 等待 DNS 和证书生效（1-5分钟）

> workers.dev 域名在国内被墙，必须绑定自定义域名才能直连。

## 测试

1. 浏览器访问 `https://你的Worker地址/translator`，应返回必应翻译网页（页面很大，200 即正常）。
2. 在 MTool 里选「必应翻译(免费)」实际翻译一句，正常会返回类似：
   ```json
   [{"translations":[{"text":"你好","to":"zh-Hans"}]}]
   ```

## 在 MTool 翻译工具中使用

打开 MTool → **API设置** 页 → 展开**代理设置**：

- **必应翻译代理**：填入 `https://bing.yourdomain.com`
- 单个地址即可（必应对 Cloudflare IP 限制较少）
- 地址留空 = 直连（不使用代理）

## 可选环境变量（高级）

通用反向代理支持以下环境变量，在必应翻译场景下通常只需要 `PROXY_HOSTNAME`：

| 变量名 | 必填 | 默认值 | 示例 | 说明 |
|--------|------|--------|------|------|
| `PROXY_HOSTNAME` | 是 | - | `cn.bing.com` | 代理目标域名（必应必须填 cn.bing.com） |
| `PROXY_PROTOCOL` | 否 | `https` | `https` | 代理目标协议 |
| `PATHNAME_REGEX` | 否 | - | `^/(translator\|ttranslate)` | 只代理匹配路径的请求（安全加固） |
| `UA_WHITELIST_REGEX` | 否 | - | `(MTool\|curl)` | 只允许特定User-Agent访问 |
| `IP_WHITELIST_REGEX` | 否 | - | `(1.2.3.4)` | 只允许特定IP访问 |
| `URL302` | 否 | - | `https://cn.bing.com` | 非法请求302跳转地址 |

> 翻译工具使用建议：只设置 `PROXY_HOSTNAME=cn.bing.com` 即可，其他保持默认。

---

## 注意事项

1. **免费额度**：Cloudflare Worker 免费版每天 **10万次请求**，翻译工具完全够用
2. **必应翻译**：对 Cloudflare IP 限制较少，推荐作为主力翻译引擎，也是谷歌 429 时的兜底
3. **返回空 / 500 排查**：先确认 `PROXY_HOSTNAME` 是 `cn.bing.com`、`_worker.js` 是本目录最新版
4. **生效时间**：Worker 刚部署或域名刚绑定，可能需要 1-5 分钟生效
5. **环境变量修改后**：必须点击**保存并部署**才会生效
